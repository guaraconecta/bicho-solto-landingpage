# 🐾 Bicho Solto — Animal Care Landing Page & Design System

Landing Page moderna e Design System com Motion & Transitions para o Petshop **Bicho Solto Animal Care** em Joinville - SC.

## 📌 Links do Projeto
- **Landing Page Principal**: `index.html` (e `index1.html`)
- **System Design com Transições**: `PET_system_design.html`
- **System Design Base**: `PET_.html`

## 🛠️ Tecnologias & Design Tokens
- **Cores**: Creme Quente (`#FBF6EE`), Marrom Pet (`#3D2B1F`), Terracota (`#C66B3D`), Laranja Vibrante (`#F4823C`), Verde Pet (`#5C8A3A`), Mostarda (`#E8B84B`).
- **Tipografia**: Fraunces (serif display), Nunito (sans body), Caveat (cursive accent).
- **Recursos**:
  - Simulador e Calculadora de Valores de Serviços em Tempo Real.
  - Alternância de Tema (Modo Escuro / Modo Claro).
  - Modal Nativo de Agendamento (`<dialog>`) com `@starting-style` e integração com WhatsApp (`(47) 99751-5499`).
  - Animações a 60fps com curvas spring e scroll-reveal.
